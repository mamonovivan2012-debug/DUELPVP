# Arena Duel — Visual Overhaul & Bugfixes (hotfix)

Проект для **Godot 4.3+**. Исходная структура и существующая боевая реализация сохранены.

## Что исправлено в этом hotfix

- Уменьшена высота главной панели, чтобы меню лучше помещалось в окне 1280×720.
- Установлен явный тёмный цвет очистки окна: если отрисовка сцены не сработает, окно не должно выглядеть как пустая серая заглушка.
- Добавлено сообщение успешной загрузки в вывод приложения.
- Добавлена строка результата раунда в HUD.
- Щупальца Тёмного принца отображаются только во время активной «Власти бездны», а не постоянно.
- Добавлена отрисовка ранее создававшихся, но не отображавшихся эффектов теневого следа и всплеска.
- Добавлена проверка индекса главы перед запуском.
- GitHub Actions запускается при push в `main`/`master` и при pull request, сохраняет логи импорта и smoke-test.
- Экспорт Windows проверяет, что PCK действительно встроен в EXE (как задано в `export_presets.cfg`).

## Сборка через GitHub

1. Загрузите содержимое репозитория и отправьте commit в `main` или `master`.
2. Откройте вкладку **Actions** и дождитесь workflow **Build Windows EXE**.
3. Скачайте артефакт `ArenaDuel-Windows`.
4. Если workflow завершился ошибкой, скачайте `ArenaDuel-CI-Logs` — там находятся `editor-import.log` и `runtime-smoke.log`.

Можно запустить workflow вручную через **Actions → Build Windows EXE → Run workflow**.

## Важно о проверке

В этой среде нет установленного Godot 4.3, а загрузить бинарник движка не удалось из-за отсутствия сетевого доступа. Поэтому здесь выполнены статическая проверка путей ресурсов, формата изображений, баланса скобок GDScript и разбор YAML workflow. **Парсинг GDScript движком, запуск сцены и экспорт Windows должны быть подтверждены результатом GitHub Actions.** Не считайте игру проверенной до успешного прохождения этих шагов.

## Управление

- Игрок 1: WASD, `Space` — атака, `Q` — способность.
- Игрок 2: стрелки, `Enter` — атака, `Shift` — способность.
- Геймпад: левый стик, `A` — атака, `X` — способность.

## Структура

- `project.godot` — настройки проекта.
- `scenes/main.tscn` — главная сцена.
- `scripts/main.gd` — игровая логика.
- `assets/` — арена, персонажи и звук.
- `.github/workflows/build-windows.yml` — CI и экспорт Windows.

## Обновление типизации и шейдеров

- Все функции `scripts/main.gd` имеют явный тип возвращаемого значения.
- Основные игровые поля и коллекции получили явные типы (`Vector2`, `float`, `int`, `bool`, `Array[Dictionary]` и типизированные массивы ресурсов).
- Добавлен `shaders/fighter_surface.gdshader`: мягкий цветной контур и анимированный блик для бойцов.
- Добавлен `shaders/void_prince.gdshader`: лёгкая деформация UV, пульсация и фиолетовая энергия Тёмного принца.
- Персонажи теперь отображаются отдельными `Sprite2D`, чтобы назначать каждому `ShaderMaterial` независимо.
- `tools/validate_project.py` проверяет наличие шейдеров и явные типы возвращаемых значений функций.

Проверка Python-валидатором не заменяет компиляцию Godot. Финальная проверка синтаксиса GDScript и компиляции `.gdshader` выполняется в GitHub Actions с Godot 4.3.
