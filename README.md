# Arena Duel — Godot 4

Фэнтезийная арена с четырьмя разными бойцами, ближним боем и способностями.

## Персонажи
- **Рыцарь** — крепкий боец, мощный выпад с тяжёлым ударом.
- **Разбойник** — быстрый, короткая перезарядка и двойной удар кинжалами.
- **Друид** — корни, которые ненадолго задерживают противника.
- **Страж** — медленный, но наносит сильный удар по земле.

## Управление
- Игрок 1: WASD, меч — Пробел, способность — Q.
- Игрок 2: стрелки, меч — Enter, способность — Shift.
- Геймпад: левый стик — движение, A — меч, X — способность. Для второго игрока используется второй подключённый геймпад; если он один, он управляет игроком 2. Клавиатура WASD остаётся доступна игроку 1.
- В PvB бот выбирает ближнюю дистанцию и использует удары/способность.

## Запуск
Открой `project.godot` в Godot 4.3 или новее и нажми F6/F5.

## Windows EXE
GitHub Actions собирает однофайловый EXE с встраиваемыми ресурсами (PCK embedded). Скачай Artifact `ArenaDuel-Windows` целиком.

## Онлайн
Онлайн-соединение оставлено в качестве раннего ENet-прототипа на UDP-порту 2456. Полноценная сетевая синхронизация атак, способностей, выбора персонажа и состояния раунда пока не реализована; основное улучшение этого обновления — локальный PvP и PvB.
