# ARENA DUEL — Dark Prince Update

Проект Godot 4.3. Это развитие исходного прототипа: сохранены основная сцена, исходные изображения героев, базовая система боя и способности пяти персонажей.

## Персонажи и бой

- **Рыцарь** — быстрый выпад и тяжёлый удар.
- **Разбойник** — быстрые атаки и двойной удар кинжалами.
- **Друид** — корни, задерживающие противника.
- **Страж** — мощный удар по земле.
- **Тёмный принц** — живая теневая субстанция. «Владения бездны» действуют 10 секунд, перезаряжаются 30 секунд, создают восемь щупалец и усиливают принца на 30% внутри территории.

Базовые параметры и механику способностей исходной игры сохранены. Тёмные щупальца визуально анимированы; попадание проверяется по их позициям.

## Режимы

- **Сюжетная кампания** — пять глав, каждая закреплена за своим героем. Встроены вступительные сюжетные эпизоды, последовательное открытие глав и сохранение разблокировки в `user://arena_duel_save.cfg`. Доступно повторное прохождение открытых глав.
- **Локальный PvP** — два игрока.
- **PvB** — бой против бота с тремя уровнями сложности.
- **Онлайн PvP** — исходный ранний ENet-режим сохранён. Он по-прежнему является прототипом сетевой синхронизации, а не законченной сетевой игрой.

Кампания в этой версии — рабочий сюжетный каркас с диалоговыми сценами и боевыми столкновениями. Полноценные исследовательские уровни, интерактивные головоломки, постановочные 3D-кат-сцены и уникальные боссы для каждой главы ещё не реализованы.

## Управление

| Действие | Игрок 1 | Игрок 2 |
|---|---|---|
| Движение | WASD / левый стик | Стрелки / левый стик |
| Обычная атака | Space / A | Enter / A |
| Способность | Q / X | Shift / X |

Распределение контроллеров:
- один геймпад — в PvB он управляет игроком 1; в локальном PvP он назначается игроку 2, игрок 1 использует клавиатуру;
- два геймпада — первый игроку 1, второй игроку 2;
- клавиатура остаётся доступной одновременно с геймпадом.

Атаки и способности срабатывают по фронту нажатия и дополнительно ограничены перезарядкой, поэтому удержание кнопки не вызывает повторные удары каждый кадр.

## Звук

Добавлены оригинальные синтезированные WAV-ресурсы: атмосферная музыка меню, боевая музыкальная петля, звук клинка, попадания, теневой способности и интерфейса. Громкость музыки и эффектов меняется в настройках и сохраняется.

Это компактная базовая аудиосистема. Отдельные музыкальные темы для каждой сюжетной сцены и уникальные звуковые наборы всех пяти героев ещё не созданы.

## Графика и рендерер

Используется исходная арена и портреты персонажей; улучшены панели HUD, отображение имён, здоровья и перезарядки, а также эффекты теневой территории. Тёмный принц сохраняет исходный спрайт, а его владения получили анимированные щупальца.

Выбран **Compatibility renderer** для более широкой совместимости с обычными ПК и драйверами. Forward+ не включён: проект остаётся 2D-игрой на Node2D/CanvasItem, а перенос на тяжёлый 3D-рендерер не дал бы оправданного выигрыша.

## Запуск

1. Установи Godot 4.3 или новее.
2. Распакуй архив.
3. Открой `project.godot` через Project Manager Godot.
4. Нажми F6/F5 или кнопку запуска проекта.

## Сборка Windows EXE

В репозитории сохранён workflow `.github/workflows/build-windows.yml`.

1. Отправь проект в GitHub.
2. Открой **Actions → Build Windows EXE → Run workflow** либо создай тег вида `v1.0`.
3. После успешной сборки скачай artifact `ArenaDuel-Windows`.

Экспорт настроен на встраивание PCK в EXE (`binary_format/embed_pck=true`), поэтому отдельный PCK не требуется. Workflow выполняет headless-импорт, пробный запуск и экспорт.

## Что проверено в этой поставке

- Состав и пути исходного архива изучены.
- Существующие изображения и главная сцена сохранены.
- Сценарий и ресурсы обновлены; пути новых WAV совпадают с preload-путями.
- Настройки проекта и workflow экспорта обновлены.

**Ограничение проверки:** в среде подготовки не удалось получить исполняемый файл Godot 4.3, поэтому фактический запуск движка, парсинг GDScript, тестирование геймпадов, воспроизведение звука и экспорт EXE здесь не подтверждены. Workflow GitHub содержит автоматические шаги для такой проверки, но до успешного запуска Actions сборку нельзя считать проверенной.

## Состав проекта

- `project.godot` — настройки Godot.
- `scenes/main.tscn` — исходная главная сцена.
- `scripts/main.gd` — логика режимов, боя, кампании, UI, сохранений и ввода.
- `assets/` — оригинальные изображения героев и арены.
- `assets/audio/` — новые синтезированные музыкальные и звуковые WAV.
- `.github/workflows/build-windows.yml` — сборка Windows EXE.
