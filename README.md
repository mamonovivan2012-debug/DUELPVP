# Arena Duel — Godot 4

Фэнтезийная арена с пятью бойцами, ближним боем, индивидуальными способностями и поддержкой клавиатуры/геймпадов.

## Персонажи
- **Рыцарь** — крепкий боец, мощный выпад с тяжёлым ударом.
- **Разбойник** — быстрый, короткая перезарядка и двойной удар кинжалами.
- **Друид** — корни, которые ненадолго задерживают противника.
- **Страж** — медленный, но наносит сильный удар по земле.
- **Тёмный принц** — бесформенная теневая субстанция. Его способность **«Владения бездны»** создаёт вокруг места схватки тёмную территорию на 10 секунд. Восемь теневых щупалец периодически наносят 5 единиц урона противнику, если тот стоит рядом с ними. Пока принц находится внутри своей территории, его скорость и урон меча увеличены на 30%. Перезарядка — 30 секунд.

## Управление
- Игрок 1: WASD, меч — Пробел, способность — Q.
- Игрок 2: стрелки, меч — Enter, способность — Shift.
- Геймпад: левый стик — движение, A — меч, X — способность. При двух подключённых геймпадах первый управляет игроком 1, второй — игроком 2. При одном геймпаде он управляет игроком 2, а игрок 1 остаётся на клавиатуре.
- В PvB бот использует ближние атаки и способности.

## Запуск
Открой `project.godot` в Godot 4.3 или новее и нажми F6/F5.

## Windows EXE
GitHub Actions собирает однофайловый EXE с встраиваемыми ресурсами (PCK embedded). Скачай Artifact `ArenaDuel-Windows` целиком.

## Онлайн
Онлайн-соединение оставлено в качестве раннего ENet-прототипа на UDP-порту 2456. Полноценная сетевая синхронизация атак, способностей, выбора персонажа и состояния раунда пока не реализована. Тёмный принц и его способность рассчитаны на локальный PvP/PvB.
