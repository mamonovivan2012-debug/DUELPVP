# Arena Duel — Godot 4

Фэнтезийная арена в тёплом каменно-осеннем стиле. Проект сделан на Godot 4, без Electron и браузерной оболочки.

## Режимы
- **Локальный PvP:** Игрок 1 — WASD + Пробел; Игрок 2 — стрелки + Enter.
- **PvB:** Игрок 1 — WASD + Пробел; бот двигается и атакует.
- **Онлайн PvP:** один игрок нажимает «Создать комнату», второй вводит IP хоста и подключается.

## Запуск
1. Установи Godot 4.2 или новее.
2. Открой `project.godot` в Godot Project Manager.
3. Нажми F6/F5 или кнопку запуска проекта.

## Онлайн
Сейчас онлайн-режим — базовый прототип обмена позицией через ENet. Для игры через интернет хосту нужно разрешить UDP-порт **2456** в брандмауэре/роутере и сообщить другу внешний IP. В одной локальной сети можно использовать локальный IP. Это не сервер с матчмейкингом; для публичных комнат понадобится отдельный постоянно работающий сервер.

## Сборка Windows EXE
GitHub Actions workflow `.github/workflows/build-windows.yml` скачивает Godot и экспортирует Windows build при создании тега `v1.0.0`. Перед этим в Godot нужно один раз установить Export Templates и создать preset Windows Desktop (workflow также использует headless export preset из `export_presets.cfg`).

Для ручной сборки: Project → Export → Windows Desktop → Export Project.

## Состав
- `assets/` — нарисованная арена и персонажи PNG
- `scenes/main.tscn` — главная сцена
- `scripts/main.gd` — логика управления, боёвки, бота и меню
- `.github/workflows/` — автоматическая сборка


## Важно: запуск Windows-сборки
Скачивай весь Artifact `ArenaDuel-Windows` и распаковывай его целиком. В одной папке должны находиться `ArenaDuel.exe` и `ArenaDuel.pck`. Не перемещай EXE отдельно от PCK.
